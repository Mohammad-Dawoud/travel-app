# FEND Capstone - Travel App

A Front End Capstone assignment for a travel-planning interface.

Udacity coursework. Technologies include JavaScript, Node.js, Webpack. Runtime and tests are pending.

Travel client logic, styles and markup plus server/API code. Omitted artwork, the fixture payload and build scaffolding. GeoNames and Pixabay literals were replaced with environment variables. Removed destination and credential-bearing debug logs.

The historical server expects `GEONAMES_USER`, `WEATHERBIT_KEY` and `PIXABAY_KEY` in its environment. The omitted setup, fixture and media are needed for the original app.
